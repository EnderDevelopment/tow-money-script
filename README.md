# Tow Money Script

Earn money while towing vehicles in FiveM with ESX.

## Features

- Earn money while towing vehicles
- Configurable cooldown period

## Requirements

- FiveM server with ESX framework
- MySQL database

## Installation

1. Download the script files
2. Place them in your FiveM server's resources folder
3. Add `start towMoneyScript` to your server.cfg file

## Usage

- Players will earn money while towing vehicles
- The amount earned is random and configurable
- There is a configurable cooldown period before earning money again

## Configuration

- `Config.MinimumAmount`: Minimum amount of money to earn
- `Config.MaximumAmount`: Maximum amount of money to earn
- `Config.CooldownTime`: Time in seconds to wait before earning money again
- `Config.TowableVehicles`: Vehicle models that can be towed
